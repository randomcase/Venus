Decentralization conceptsettled

No participant reads any other. Removing one changes nothing for the rest.

Not "spread out", not "many copies", not "no company owns it". Those are consequences people notice and then mistake for the thing. The property is about READS: a system is decentralised exactly to the extent that no component's behaviour is a function of another component's state.

The automat is the cleanest instance in this yard because it was built to have nothing else in it. Each tribe keeps its own beat, off its own prime, and advances on beats that divide its own period. No tribe queries another. There is no coordinator, no scheduler with a policy, no leader election, no consensus round — the pattern you see on the board is not produced by anything, it is what falls out of several bands not talking.

Which is why removing one is a non-event. Delete a tribe and the remaining ones do not slow down, re-balance, or notice. That is not resilience bolted on afterwards; there is no failure mode to be resilient to, because there was never a dependency to break.

the test

Delete one component. If any other component's behaviour changes — timing, output, ordering, anything — it was not decentralised, and the coupling you just found is the real architecture.

Fungibility conceptsettled

No unit is worth more than another, and there is no way to write the function that would prefer one.

The test is constructive and it is the whole of the idea: try to write the preference. If you can write a function that ranks two units, they are not fungible, and the ranking is where the rent will be collected. If you cannot write it — not "choose not to", cannot — they are.

This is why the automat has no scoring function. Not as restraint, as a structural fact: there is no goal state to compare an arrangement against, so there is nothing for a ranking to be a ranking of. Every arrangement is reachable from every other and none is worth more, which means there is no arrangement anybody can be induced to reach and none anybody can be charged to leave.

The correction that produced this entry is worth keeping. Early in this repository's life the advice was to add a loss condition and a scarcity to make a game feel like a game. That advice was wrong in a specific way: fungibility exists to remove exactly those two things, and putting them back is not balancing a system, it is un-building it.

the test

Write the preference function over two units. If it compiles, they are not fungible. If it does not, ask what the syndicate would have to add before it could — that addition is the attack.

What it takes to start something conceptsettled

Not the most important thing. The smallest closed loop in which every part is fed by another part.

The instinct is to start with the root — the biggest, the most depended-upon, the one everything else needs. This yard tested that instinct and it fails, visibly, on a board you can open. Turn on Zeus alone in the twelve-sector economy: nought working, one broken. Add Hera: still nought, still broken. Turn on all four roots — the four sectors with the most downstream dependents — and you get two capabilities and nobody eating.

A root is not a start, because a root is defined by what depends on IT and a start is defined by what feeds IT. Those are different arrows. Something with no inputs produces nothing on its own; it only becomes productive once the things that consume its output exist and return something to it.

So the thing you need is a CYCLE: the smallest set whose members feed each other with no external input required. Not the most important sector — the shortest closed loop. In practice that loop is nearly always unglamorous and involves food, water, and somebody keeping time, because those are the three that everything else quietly assumes. The dependency graph will tell you which loop is shortest; it will not tell you which node is most important, and it does not need to.

The same shape appears in the fourteen terraforming profiles. The envelope has ten downstream dependents — the most of anything on the board — and its own status is only "derived". The most-depended-on thing in the system is a thing nobody has independently established. That is normal, and it is exactly why you do not start there.

the test

Invert the dependency graph and look for cycles, not for maxima. If your proposed start has no path back to itself, it is a root and not a start, and it will sit idle producing nothing until you build the return arrow.

Smart contracts mechanismcontested

Code that guarantees execution, not truth. It enforces the terms it was handed and never asks whether they are fair.

What a smart contract actually promises is narrow and worth stating plainly: given these inputs, this code runs, deterministically, and everyone can check that it ran. That is a real guarantee and it is the only one. It says nothing about whether the inputs were true, whether the terms were reasonable, or whether the parties understood them.

Everything the contract knows about the world arrived through somebody's hand. That is the oracle problem and it is not a rough edge to be engineered away — it is structural. A contract that pays on delivery cannot see a crate; it sees a signature asserting a crate. So the discretion did not disappear when the code went on-chain. It moved to whoever signs, and to whoever wrote the terms, and to whoever gets to say what the words in the terms refer to.

THIS ENTRY IS MARKED CONTESTED BECAUSE THIS REPOSITORY HAS SAID TWO THINGS. One position: there are no blockers, smart contracts prevent syndication — if allocation is in code and no human chooses who receives what, the classic move of matriculating funds upward and promoting within has nowhere to happen. The other, from theory.md: a syndicate's only move is de-fungibilisation, and de-fungibilisation happens in the noun, off-chain, before anything reaches a contract at all.

The reconciliation, as far as it goes: A CONTRACT CAN CLOSE THE DISCRETIONARY PATH AND CANNOT CLOSE THE SEMANTIC ONE. Where the allocation is genuinely mechanical, the first position holds and it holds strongly — that route really is shut, and shutting it is not nothing. But the rename is upstream of the contract, and a contract handed the renamed thing will execute against it faithfully and irreversibly, which is worse than a clerk who might have hesitated. Neither position is wrong about its own half and the yard has not shown a board where both halves are in view at once. Until it does, this stays contested.

One scope rule this yard did adopt and does keep: SMART CONTRACTS ARE FOR WALLET TRANSACTIONS. Not membership, not governance, not adjudication. The moment a contract is asked to decide who belongs, it has become a bench — and a bench that cannot be appealed is strictly worse than one that can, because appeal is the only mechanism anybody has ever built for the case where the rule was right and the outcome was wrong.

And a contract is only as good as the checks somebody paid for. contract.html gives that cost a name: gas. A check nobody paid for is a check nobody ran, and an unpaid check looks exactly like a passed one from the outside.

the test

Follow the value and find the last point where a human chose. If there is one, the contract automated the disbursement and not the decision — syndication lives at the choice, not the transfer. If there genuinely is none, stop looking there and ask two questions instead: who wrote the terms, and who gets to say what the nouns in the terms refer to.

The narrowest identity there is: it can hold and it can sign. It has no memory of why.

Romulus is one thing, a wallet. Remus is all things — everything not Romulus. That split is exact and it is the most useful definition of a wallet anybody has offered in this repository, because it defines the thing by its complement.

A wallet is not a person, not a role, not a reputation, not a history, not a standing, not an obligation. It is an address, a balance, and the capability to sign. Every attribute an institution normally carries lives in the complement — which is why the complement needs a name of its own and why calling it Remus rather than "metadata" was the right call.

That narrowness is a feature exactly once: it is the precise amount of identity an autonomous agent needs. An agent with a wallet can participate without anybody first having to decide what it is, which is why two made agents who are not required by anything can try anyway, and keep trying, and the ledger has no way to object.

THE FINDING IS THE SILENCE. A wallet records that value moved and never what for. It is complete about quantity and silent about reason — and the reason is where the syndicate lives. This is the same shape as the bench's named counter: the transfer is in the record and the drafter is not, and no amount of auditing the transfers recovers the drafter.

The ledger mechanismsettled

Its guarantee is agreement about ORDER, not about truth. It is complete about what was submitted and silent about what was not.

A wallet holds and signs. A ledger is the record, and the two are constantly confused because they arrive in the same box. The ledger's actual promise is narrower than either its defenders or its critics usually state: these events happened in this sequence, and everyone reading sees the same sequence. Consensus is a mechanism for agreeing on ORDER. It was never a mechanism for agreeing on whether anything in the order was true.

APPEND-ONLY MEANS AN ERROR CANNOT BE CORRECTED, ONLY SUPERSEDED. The mistake stays; the correction is a second entry; and from then on both are in the record permanently and every reader has to know which one governs. That is the integrity guarantee and the liability in one property — immutability is exactly what makes a record trustworthy and exactly what makes a single bad entry load-bearing forever.

The second property is the one nobody draws. A ledger is complete about what was SUBMITTED to it and knows nothing about what was not, and THERE IS NO ENTRY REPRESENTING THE GAP. An event that never reached it leaves no hole, no null, no marker — the record simply reads as though the world contained only what was written down. This is the same shape as the bench's named counter reading zero, except worse in one specific way: named is at least printed. The ledger's absences are not.

Which is why this yard's ledger is built to carry the thing a chain does not. bank.html holds no key and no balance and every figure is arithmetic summed from what you select — but every line says WHICH BOARD AUTHORED IT. Provenance is not part of what a ledger guarantees, and it is the first thing anybody actually wants from one.

exhibit.html is the same principle in a court record and states it better than an argument could: the transcript is entered verbatim and nothing is corrected — not the spelling, not the half-sentences, not the lines that turned out to be the holding. A transcript that has been tidied is a summary, and a summary is the other side's argument wearing the record's clothes.

The price of a check. Its point is not revenue — it is that an unpaid check and a passed check look identical from outside.

A form is not complete when its boxes are full. It is complete when every check it carries has actually been performed, and checking costs something. Naming that cost is the entire contribution: once verification is metered, "we checked and it was fine" and "we did not check" stop being indistinguishable, which is the state they are in everywhere the cost is unnamed.

The rule in this yard has three arms. Gas within budget: complete, the checks were affordable and were done. Gas over budget but a higher budget exists: return it, escalate to a desk that can pay. Gas over EVERY budget: BURN — refuse it, and forfeit what was already spent.

The burn is the part that matters and it is not vindictive. A partially checked form that gets accepted becomes evidence that it was checked, and that is strictly worse than a refusal: a refusal leaves a gap where the truth is, and a rubber stamp fills the gap with a lie. The gap is recoverable. The lie is not.

AND THE ATTACK RUNS THE OTHER WAY FROM WHERE PEOPLE LOOK FOR IT. Nobody is collecting this gas. The syndicate's move is not to charge for verification, it is to RAISE the cost of it — the syndicate profile in that board is heavy on purpose, because the shape's whole method is to make checking cost more than waving it through. A document nobody can afford to verify gets waved through by an honest desk with a full budget, and no bribe was needed anywhere in that sentence.

AND IT IS A SCARCITY THAT CARRIES NO RENT, which is worth stating because the reverse is assumed. A budget that can run out is a last unit, and a last unit is normally where a market in continuation appears — somebody sells you more. Not here. The burn FORFEITS what was spent rather than transferring it, so running out enriches nobody and there is nothing for a rent to attach to. The general form: a scarcity is only a rent when somebody collects at exhaustion. Find the beneficiary before calling a cost a racket; a real price with no collector is a different object from a manufactured one with a desk behind it.

the test

Find who receives what is spent when the budget runs out. If it is transferred to anybody, you have found the beneficiary and the scarcity is a rent. If it is forfeit, it is not. Then ask the question people skip: who benefits from the cost being HIGH? That party never appears in the fee flow at all.

The rename mechanismsettled

De-fungibilisation done entirely in the noun. Nothing is destroyed and four capabilities become four line items.

A syndicate does not need to destroy a commons. Destroying things is expensive, visible, and eventually illegal. It needs the commons RENAMED, and then removing it is somebody's contract — renewable, with a schedule of fees.

The forest floor is the demonstration because the substance is identical under both names. Called the floor it is eaten by the beetle, threaded by the fungus, carried as seed, and becomes the tree: four capabilities of the matter itself. Called waste it is hauled, fined, buried, and billed: four services performed on it by somebody with an invoice. The matter counter reads 1 on both sides of the board. The capability counter does not.

And the capabilities are not gone under the second name. They are physically still there — the beetle would still eat it — they are merely unreachable, because it has been hauled somewhere the beetle is not. That is the difference between destruction and enclosure, and enclosure is the cheaper of the two by a wide margin.

the test

Hold the substance fixed and change only the noun. If the list of things it can do changes, the change was never about the substance, and somebody is being paid for the difference.

Caught up conceptsettled

A medium moving faster than the thing it rests on, carrying whatever is in it, with no discontinuity in it.

A quiet storm set and a Venusian superrotation are the same object described twice. In both the passenger supplies no energy: the set carries the room, the band carries the balloon. Being carried is not a failure to travel — it is the mechanism.

Both are ruined by the same event, which is an ANNOUNCEMENT. The DJ saying the time, or a thruster firing. Either is a discontinuity you can perceive, and the instant there is one you are aware of the mechanism instead of the thing: listening to a radio station, or flying an aircraft. Not carried.

Superrotation numbersettled

The solid planet turns once in 243.02 days. The cloud deck laps it in about four and a half.

Venus rotates once every 243.02 days, retrograde, with a solar day of 116.75 days. The atmosphere does not go with it: the cloud deck at roughly 65 km is carried at about 100 m/s and circles the entire planet in four to five Earth days. After sixty years of measurement there is no agreed account of what sustains it.

The arithmetic, so it can be checked rather than believed: 6051.8 + 65 = 6116.8 km radius, circumference 38,433 km, at 360 km/h that is 106.8 hours or 4.45 days. Divide 243.02 by 4.45 and you get about 55 laps per solid rotation, or 54 relative to the ground since the body turns the same way.

The figure people quote is sixty. The wind is not one number — it runs roughly 90 to 110 m/s across the deck and varies with latitude and altitude — so the honest statement is four to five days, call it sixty-ish laps, and the honest way to say that is to show the division and let the reader see how loose it is.

the test

Do the division yourself with a different wind speed from the published range and see how far the answer moves. If a page gives you one confident figure and no division, it is claiming a precision the measurement does not have.

Hydrogen is the only scarcity numberworking

Carbon, oxygen, nitrogen and sulphur are all abundant on Venus. Hydrogen is not, and everything wet depends on it.

Venus has carbon and oxygen in enormous quantity, locked in CO₂, and sulphur in the clouds. What it does not have is hydrogen — it is 2.06% by mass of sulphuric acid, and processing a cubic metre of cloud yields almost nothing. Roughly 136,000 m³ of cloud per kilogram of water.

That single fact reorganises the whole settlement problem. Water is not a supply question, it is the supply question, and every other requirement in the fourteen profiles is downstream of whether hydrogen arrives or is extracted. It is also the one genuine scarcity in a system otherwise built to have none, which makes it the place to watch: a real scarcity is where a rent can attach, and this one is real.

The altitude follows from it too. 1.00 bar and 0–50 °C are about five kilometres apart in altitude, and dissolved oxygen moves the settlement from 50 km to 55 km. Tether strength was never the descent problem — 55 km sits inside four fibres' breaking lengths. Heat is, and heat is gradable.

the test

Trace any requirement in the profiles back along its inputs. If it terminates at water and the water terminates at hydrogen, it is in the constrained set. If a proposal claims to avoid this, ask where its hydrogen comes from and in what mass.

When an outcome depends on two or three inputs together, there is no expression available — there is a row per combination, and somebody typed every one. Three inputs by four options is twelve rules. Reading × circuit × hour is twenty-four.

The cost is that a reader must trust the file — a counter incremented nowhere is indistinguishable from a counter someone forgot to wire. Which is why the pages that use it say so in the stylesheet, in the comment next to the declaration, where the person checking is already looking.

The half of the URL CSS cannot read mechanismsettled

CSS reads the fragment through :target. It cannot read the query. Nothing can. So that is where the script layer lives.

A document has exactly one :target at a time, and the fragment is the only durable state a scriptless page has — it survives reload, it is in the bookmark, it goes in a message, Back is undo. The query string is the other half of the same address and it is invisible to the style layer completely.

That asymmetry is not a limitation to work around, it is a channel. automat.js and devmode.js are wired into every page in this yard and are inert unless the address carries ?run or ?dev. Open a board plainly and nothing runs and the stylesheet decides everything, exactly as before. Open it with a query and a script is pressing the controls — and the two layers cannot collide, because they read different halves of the same URL.

The claim was never that there is no script file. It was that the logic is the cascade, and that is intact and now checkable from inside the page.

the test

Open any board without a query string and count the script tags that do anything. Then open it with ?dev and use CENSUS, which counts them for you and says which are inert.

The orbit numbersettled

lcm over the tribes of (period × steps). The beats before a board is in an arrangement it has held before.

It is the honest measure of an endless thing, and it is computed in two places independently — in the HUD at runtime and in the generator that builds the wall — rather than asserted in either.

It matters because "endless" is cheap to claim. A run whose components all move on period 1 only ever visits the diagonal of its state space and returns to the start almost immediately; it looks endless and is a short loop. Coprime periods make the combined orbit the lcm, which for a board with a sixteen-checkbox bank leaves the safe integers early enough that the arithmetic has to be done in BigInt.

So the number is a claim you can check about a property you would otherwise have to take on faith, which is the same move as the zero counter and the printed division.

the test

Set every period to 1 and compute the orbit again. If a system's endlessness survives that, it was structural; if the orbit collapses to the number of steps in one component, the endlessness was the cadences and not the design.
