the floor press once; it does not need you again

Coprime, and that is the whole trick. Every cadence is prime, so no two share a factor and the board returns to its opening phase only after 30,030 ticks. Nothing stacks, nothing spikes, and the load is flat forever — which is why an idle game built this way has no failure mode rather than a rare one.
And nothing recurses. An agency feeds another agency, never itself and never anything that comes back to it. agencies.mjs found 48 cycles in the first arrangement, broke 47 to the sink, and then re-ran the detector — because a cycle check that only runs before the fix has never seen the fix work. Zero remain.

what was refused, and why 83 roots

The roots handed over included .ssh, .gnupg, .kube, .azure, .docker, .claude.json, .bash_history and NTUSER.DAT. Those are key material, session tokens and a registry hive. Templating them would have put private keys into generated HTML, and a generator that did it quietly would be the worst thing in this yard.

So the deny list is a rule in a file, applied before anything is read, with every refusal written to exclusions/. Nothing inside a denied root was opened, listed, or hashed. An exclusion nobody can read is indistinguishable from an oversight.
One heuristic will occasionally be wrong: a dotfile directory with no README is treated as tool state rather than work. If something was skipped that should not have been, put a README in it and run it again. That is a cheaper fix than a longer list.
