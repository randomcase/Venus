What actually happens when you press it. The browser reads the form, encodes the hidden field into a query string and opens bridge.html with it. That is the entire API call — no fetch, no endpoint, no server, and nothing sent anywhere but to another file on this disk. This page contains no <script> that runs; the block above is type="application/json", which the browser stores and never executes, and it is printed verbatim so what you see is what goes.

The clause, since it is in there. It fires on a cap the document names, and only on that: over the line, the run is marked shut down, the assessed sum is recorded as forfeit, and the pre-seizure ledger is preserved so anyone can recompute the finding and check it. A syndicate that can dismantle a syndicate is only tolerable if its arithmetic is in the open — so it is. Raise cap_heze and it stays quiet; lower it and watch it bite.
