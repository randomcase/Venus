The parliament

nine owls, four aspects, two packs of oatmeal

You are ranged and this board cannot call you. So it does not try: no notification, no alarm, nothing that buzzes. It is a signal, and a signal is the solved version of exactly this problem — a railway driver cannot be telephoned either, so the aspect has to be legible from far enough away to act on and mean the same thing every time to somebody who is not paying attention.

Built by owls.mjs, which computes the state into api/owls.json and writes nothing else about it. The board is owl-app.js — React components, run by owl-runtime.js, ninety lines and no off-origin request. Swap that runtime for react/react-dom and the components are unchanged.
The oatcoin is a real ECDSA P-256 signature over the crate manifest, minted and verified in this browser with a non-extractable private key. It is a seal, not a currency — no chain, no transfer, no balance.
