Bare

Three techniques. Everything else is built out of these.

1 · CSS can add

Total:

Real arithmetic, done by the browser's layout engine. It adds and does nothing else — no subtraction, no multiplication. If you need a product, write the products out. If you need a difference, show both numbers and say why the difference is missing. Never print a figure the page did not compute.

2 · An ancestor can see its children

The switch is on.

The switch is off.

body:has(#no:checked) .on { display:none } — that is the entire state machine. Nothing to keep in sync, because there is only one copy of the truth: the DOM.

3 · What is written last, wins

The stop rule sits below the speed rule in the stylesheet, so it wins. Put it above and it silently does nothing — which is how a brake becomes a suggestion.

That is the bare version. Two more things you will want, both one line each: form="x" on an input associates it with a <form action="next.html" method="get"> anywhere on the page, so a button can carry your state to another file with no script; and <script type="application/json"> parks data in a page without executing it.
