Venus Yard

Seventeen boards, a template and one contract. Draw a hull and count its fastenings, order it against a price list, man it, provision it, run it down a lane — and carry one JSON document between them. Sixteen of the eighteen have no script in them at all; the arithmetic is CSS counters and the state is :has(). The seventh is the bridge, and it is marked.

How a document moves

station.html → personnel.html → cruise-control.html → bridge.html → next cycle Each board authors its own section and reads the rest. The bridge is the only thing that recomputes anything, and it trusts none of it.

What this is. A set of local HTML files that draw ships, count their parts, price them, staff them and run them down a lane. Nothing in the yard makes a network request, signs anything, transmits anything or settles anything — the address fields are read locally to seed a drawing, and the prices are denominations inside the project. There is no token, no chain, no contract deployed anywhere, and nothing here is an offer or financial advice. The one page with JavaScript in it is the bridge, which is exactly why it says so on its own chip.
