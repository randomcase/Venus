what this file refuses

To print a token. Every string is passed through a GitHub-token pattern on its way to the page — gho_, ghp_, github_pat_ and the rest — and the redactor runs on everything rather than at the point somebody remembered to call it. A remote URL with a token embedded in it comes out redacted whether or not anybody anticipated that URL.
To read repository contents. It asks git for metadata and never opens a file inside a project. An inventory does not need to know what is in the boxes, and one that looked would be doing something other than an inventory.
To guess. See above. Silence is its own column.

the smallest useful next move

Not "commit everything" — 30,490 files is not a commit, it is an archaeology project. The cheap win is the 25 projects with nowhere to push: those are one gh repo create each and they go from total loss to recoverable. The exposed ones already have a home and are a different, slower problem.
And the inventory is now a file — templates-github/inventory.json — so the next run can be diffed against this one. A number that only exists on a page nobody re-reads is a number that stops being true quietly.
