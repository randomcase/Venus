Patterns

Six shapes, compiled out of 49 authored pages and 1424 matching rules. Nothing on this page was typed by hand except the reasons. The counts and the code are lifted from the corpus by compile.mjs, and the sample shown for each pattern is the shortest real instance of it in the repository — not an example written for a documentation page, but the smallest line actually doing that job somewhere in the yard.

There is no colour scheme here. A pattern is a selector shape; the moment a pattern library ships a palette it has become a framework, and the forty-one per-page templates in this folder already carry every palette anybody needs.

Counters are arithmetic The browser adds for you

Declare the counters once on body, increment where the state changes, print with content:counter(). The total is not stored anywhere and cannot disagree with the inputs, because it is recomputed from them on every repaint. A counter can only be printed after the things that increment it — inputs first in the DOM, totals after, layout put back with grid. That single constraint is why every board in this repository is arranged the way it is.

.cap .mk{counter-increment:can 1}

:has() is state An ancestor styled by what is inside it

A state machine with nothing to keep in sync. The most common way to get it wrong is scope: the rule must be anchored on an ancestor of both the switch and the thing it drives, and a rule scoped to the wrong ancestor fails silently — no error, nothing happens, and it looks like the property is unsupported.

used449 times across39 pages smallest real instance, fromgrades.html 
.g:has(#g0:target) .v0{display:block}

Compound :has() is a lookup Two keys, one answer

How you get multiplication out of a language that has none: you write the products. Three options by two states is six rules and there is no shortcut — but every cell was typed by someone who can be asked about it, which is a better property than most computed tables have. Adding an axis costs rules linearly and adds cells combinatorially, and the moment you want to avoid that cost is the moment to re-read what it buys.

used349 times across30 pages smallest real instance, fromconvoy.html 
.board:has(#o-4:checked):has(#r-a:checked) .g1{opacity:1}

:target is the store State that survives a reload

The URL fragment is the only durable state a scriptless page has and :target is the only selector that reads it. A link writes it, the browser keeps it in history, and reload restores it. The price is exact: one target per document, so a stored value must name a whole combination and there is no partial update. Nothing in CSS can read the query string — that half of a URL is write-only from here.

.p:target{display:block}

Cascade order is authority What is written last wins

Later rules beat equally specific ones above them, so the rule that must not be overridden goes last. Cascade order only settles ties. A stop rule with fewer :has() in it than the rules it is trying to beat loses outright, silently, and typically works on exactly the cases you would test first — see the note at the foot of ecosystem.html, where that happened and is kept in place.

used48 times across23 pages smallest real instance, fromeros.html 
body:not(:has(.p:target)) #p1{display:block}

A GET form is transport The browser serialises and navigates

No fetch, no endpoint, no server. form="vy" associates an input with a form anywhere in the document, so the markup does not have to be reorganised around the transport. On submit the browser encodes the checked inputs into the query string and opens the target.

Syndication versus automation. The templates beside this file are one per page, each carrying its source page's entire stylesheet — the same six ideas copied forty-odd times in forty-odd palettes. That is useful for starting a board and useless for changing one: alter how a counter works and it is forty-one edits with no way to know you found them all. This file is the other direction, and it is regenerated rather than maintained. If a number here is wrong, the fix is to run the compiler, not to edit the page.
