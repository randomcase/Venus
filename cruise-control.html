What was taken out

Every blocker, on instruction. The red aspect is gone, the four station stops are gone, the master stop is gone, and demurrage went with them — nothing is held, so nothing accrues for being held. The file runs from the moment the page opens and the only thing that stops it is closing the page.

That is a real change and it is worth being clear about it, because the board was built the other way round: three levels of stop, each one above the last, specifically so that no state could be entered that something above it could not end. That property is now gone. It is one commit back if it is wanted, and it does not need rebuilding.

What is left is the point. One lane. One file of eight, nose to tail, the same run started at eight different moments. One control over all of them, and three settings, none of which is a hold. Four stages taking their tariff as the file passes, and one number at the bottom that is the whole of what the lane earns on a pass. Every figure here is a CSS counter and there is no script in this file.
