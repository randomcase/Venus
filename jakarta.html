Jakarta

A small station on one of her islands, and the only page in this yard that faces the other half of the repository — the Scala side. Forty-six files and four thousand seven hundred and thirty-eight lines of it, sitting quietly one directory up.

Why a cultured pearl

nucleus A bead is put in on purpose. Nothing about a cultured pearl is accidental at the centre — somebody chose the beginning and the size of it.
nacre The animal then lays aragonite and conchiolin around it in microscopic layers, for two to four years, at its own rate. The material is identical to a wild pearl's. The only difference is that the middle was intended.
the point Which is exactly what a codebase is. Somebody inserted a small deliberate thing — a data model, three files, a package name — and everything since has been laid down around it in layers by whoever showed up. Seeded, not grown wild, and none the worse for it.

The seed

One directory up from this page there is a Scala package, io.cityoflight.virgo.scala, and it holds three files. The nucleus of the whole thing is one sealed trait — the same idea the yard has been running on all along: a ledger, a queue, and a record that knows what it is.

sealed trait LedgerQueueItem {
  def id: String
  def starTag: String
  def planetaryTag: String
  def targetArtifact: String
  def description: String
  def scoreTag: String
  def status: String
  def timestamp: String
  def isHighPriority: Boolean = false
}

Sealed means every implementation must live in that one file, so the compiler can check a pattern match is exhaustive. There are two: StandardLedgerRecord, and HighPriorityLedgerRecord, which adds a priorityReason and overrides the flag to true. A record that claims priority has to say why — which is the same rule the powers block applies to a clause, arrived at independently, in another language, by whoever wrote this first.

The service around it is GeminiScalaLedgerQueueService with enqueueItem and dequeueItem — a queue, and the ledger the yard's boards have been imitating in CSS counters this whole time. the ledger-queue book walks all three files.

On the name

Three things at once, and all of them meant.

Jakarta is on Java. When the javax.* namespace was handed over, the JVM world renamed it jakarta.* — so a station called Jakarta, standing for the Scala half of a repository, is a joke that tells itself. Scala is a JVM language; the island is the platform.

Indonesia is where the pearl is actually from. Pinctada maxima, the South Sea oyster, farmed off Lombok, Sumbawa and Papua — the largest cultured pearls in the world come out of those waters, and the industry is a real one, not a metaphor borrowed for the occasion.

And a cultured pearl is the honest description of a codebase. Not found, not wild, not grown by nature — seeded on purpose and then layered by time and whoever was there. The nacre is identical to the wild kind. The only difference is that someone chose the middle, which is the least shameful thing about it.
